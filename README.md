# faucet-app-releases

Dữ liệu công khai cho app faucet: `data/stats.json` (tự cập nhật mỗi 3 giờ), `data/catalog.json` (link giới thiệu, chu kỳ claim, nút Claim), `data/ads.json` (quảng cáo), `data/version.json` (bản app mới nhất).


Bản app: nhánh `apk` chỉ giữ 2 bản mới nhất: `faucet-app.apk` (mới nhất) và `faucet-app-prev.apk` (bản trước). Bản cũ hơn bị xóa.
